# Cloud Architecture & Well-Architected Framework (AWS / Azure / GCP)

> **Tài liệu Cloud Architecture**: 6 Trụ cột đám mây: Operational Excellence, Security, Reliability, Performance Efficiency, Cost Optimization, Sustainability.

---

## 1. 6 TRỤ CỘT ĐÁM MÂY DÀNH CHO ENTERPRISE
1. **Operational Excellence**: Tự động hóa IaC, CI/CD pipelines, Observability.
2. **Security**: Zero-Trust Architecture, Identity & Access Management (IAM), Data Encryption at Rest/In-Transit.
3. **Reliability**: Multi-AZ deployments, Auto-healing, Disaster Recovery.
4. **Performance Efficiency**: Edge Caching (CDN), Auto-Scaling, Serverless.
5. **Cost Optimization**: Auto-scaling down off-peak, Spot/Reserved instances.
6. **Sustainability**: Tối ưu tài nguyên tiêu thụ năng lượng xanh.
