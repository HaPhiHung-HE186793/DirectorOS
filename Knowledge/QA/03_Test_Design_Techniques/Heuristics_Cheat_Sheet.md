# Heuristics Cheat Sheet for Software Testing

> **Tài liệu QA Cheat-Sheet**: CRUD, Goldilocks, Follow the Data, Some/None/All, Zero/One/Many.

---

## 1. BẢNG NGUYÊN TẮC SUY NGHIỆM TÌM LỖI SÁNG TẠO
- **CRUD**: Kiểm tra chuỗi Create → Read → Update → Delete.
- **Goldilocks**: "Quá nhỏ, Quá lớn, Vừa vặn".
- **Follow the Data**: Nhập → Tìm kiếm → Báo cáo → Xuất file → Nhập lại.
- **Zero, One, Many**: Đánh giá xử lý mảng phần tử rỗng (`0`), một phần tử (`1`), hoặc danh sách cực lớn (`Many`).
