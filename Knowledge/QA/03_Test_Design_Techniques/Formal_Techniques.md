# Formal Test Design Techniques (Black-Box & White-Box)

> **Tài liệu QA Standard**: Equivalence Partitioning, Boundary Value Analysis, Decision Tables, State Transition, Statement & Branch Coverage.

---

## 1. PHƯƠNG PHÁP THIẾT KẾ TEST CASE CHUẨN
- **Black-Box**: Phân vùng tương đương (Equivalence Partitioning), Giá trị biên (BVA), Bảng quyết định (Decision Tables), Chuyển trạng thái (State Transition).
- **White-Box**: Bao phủ câu lệnh (Statement Coverage), Bao phủ nhánh quyết định (Branch Coverage).
